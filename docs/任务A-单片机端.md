## 3 传感器驱动（预计1.5天，三个驱动相互独立，可并行或裁剪）

### A3.1 DHT11（必做）
- 接线：DATA → **PB5**，VCC-3.3V，DATA外接4.7k~10k上拉（模块自带可省）
- 时序要点：主机拉低≥18ms → 释放（切输入）→ DHT11回应 80us低 + 80us高 → 连续40bit（每bit：50us低 + 26~28us高=0 / 70us高=1）→ 数据为 湿度整数.湿度小数.温度整数.温度小数 + 校验（前4字节和的低8位）
- **注意**：全程关中断或用SysTick微秒延时；两次读取间隔 ≥ 1s
- 验收：读值与实际室温一致（±3℃内），连续读取10分钟无校验错误；读取失败（超时/校验错）时**沿用上次有效值并置传感器状态位**，不得发送脏数据

### A3.2 MQ-2 烟雾（推荐做）
- 接线：AO → 分压电阻 → **PA0**（ADC1通道0）。**MQ-2模块5V供电、AO输出可达5V，STM32 ADC上限3.3V，必须分压**（如 10k/20k 分压后 ≈ 2/3×AO）；模块需预热2~3分钟
- 实现：单次转换，8次采样取中值滤波
- 验收：预热后稳定值 < 400（洁净空气），酒精棉/打火机（未点火放气）靠近时数值明显上升

### A3.3 BH1750 光照（推荐做）
- 接线：SCL→PB6，SDA→PB7（I2C1），ADDR接地（地址0x23），3.3V供电
- 实现：发送测量指令 0x10（连续高分辨率模式）→ 180ms后读2字节 → lux = (high<<8|low)/1.2
- 验收：手机手电筒照射 > 1000 lux，手掌遮挡 < 50 lux

### 裁剪规则
若 BH1750/MQ-2 缺件或损坏：帧内传感器个数减为2（仅温湿度），**帧格式本身不变**（客户端按个数字段自适应）。在 `接线表.md` 中注明实际配置。

## 4 主循环集成（预计0.5天）

- SysTick 2s 定时 → 采集全部已启用传感器 → `build_sensor_frame` → UART1发送
- 验收：串口助手HEX窗口连续观察10分钟：每2秒一帧、帧长固定、随机抽查3帧手工验校验和均正确

## 5 联调（预计0.5天，需与任务B配合）

1. 接入B的客户端（或先用 `simulator/stm32_sim.py` 对照双方输出）
