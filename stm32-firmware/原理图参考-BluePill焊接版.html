机房环境监测系统 · 原理图参考（Blue Pill + 万能板焊接版）

主控：STM32F103C8T6 最小系统板（Blue Pill）  |  供电：模块自带 Micro-USB 口取 5V  |  装配：万能板手工焊接（取消面包板 / 杜邦线）

这一版和上一版（裸片焊接版）的区别
上一版用裸芯片 STM32F103C8T6，原理图里必须自建一整块最小系统。
这一版改回 Blue Pill 最小系统模块，下面这些全部由模块板自带，原理图里不需要画了：
  • 8MHz 晶振 Y1 + 22pF 负载电容
  • 复位电路（10k 上拉 + 100nF + 轻触按键 SW1）
  • BOOT0 / BOOT1 跳线（板上两个跳线帽）
  • 3.3V 稳压器（AMS1117 / RT9193）+ 输入输出滤波电容
  • Micro-USB 座 J1 + 电源指示灯（PWR LED）
  • MCU 去耦电容组 C5~C8、VDDA 滤波
所以本图 = 模块 + 4 个外设 + 1 处分压 + 3 根电源干线，焊接点比裸片版少一大半，成功率也高得多。
但有一件事完全没变：MQ-2 的 10k/20k 分压必须保留。 换主控不改变 STM32 的 ADC 上限（3.3V）。

5. 万能板焊接装配指南

5.1 布局规划（先在纸上排一遍再动锡）

  • 中央偏上：Blue Pill 的 2×20 排母座，USB 口朝板边，插上模块后数据线不挡其它件。
  • USB 口一侧留空：至少留 15mm，否则 USB 线插不进去。
  • 板边：四个模块排母分散放在三边，DHT11 尽量远离 MQ-2（MQ-2 加热丝发热会影响温湿度读数）。
  • 靠 PA0 附近：R1/R2 分压电阻紧挨着放在 PA0 引出脚旁边，节点到 PA0 的线越短越好。
  • 电源干线：在万能板上用三根「加锡堆粗」的线分别做 3V3 / 5V / GND 干线（或各用一根镀锡铜线沿板边走），所有器件就近搭接。
  • GND 走星形：所有模块的地都单独汇到同一根地干线，不要串联成一条长链，避免地环路。

5.2 焊接顺序

  1. 先焊 电阻 R1 / R2 / R3——最矮，不受后面元件遮挡。
  2. 再焊 所有排母座（Blue Pill 的 2×20、四个模块插座）——高，且焊点多，先做完便于后面飞线。
  3. 然后焊 电源干线（3V3 / 5V / GND 三根加锡线）。
  4. 最后走 信号飞线（漆包线按第 2 节的连接表逐条飞）。
  5. 焊完 先不要插模块，用万用表检查：各排母的电源脚与地之间不短路。
先验电、再插模块，这一步不能省。
排母与飞线焊完后，插上 Blue Pill（模块不接任何传感器），通电看 PWR LED 是否亮，再用万用表量排母上的 3V3 与 5V 排针电压是否分别为 3.3V 和 5V。
确认无误后，断电再逐个插上 DHT11 / MQ-2 / BH1750 / CH340。这样即使某处焊错，烧的也只是模块而不是全套传感器。

5.3 走线与工艺要点

  • 电源线和地线走粗：多用几个焊盘串联，或沿走线加锡堆厚，降低压降。
  • 信号线用 0.3~0.5mm 漆包线飞线，走最短路径，尽量贴着板面走，避免交叉时压到元件脚。
  • MQ-2 节点A 到 PA0 的线尽量短，且远离 5V 走线和 MQ-2 加热丝回路（否则 ADC 读数会带噪声）。
  • I²C（PB6/PB7）与串口（PA9/PA10）分开走，不要长距离平行，避免串扰。
  • Blue Pill 排针比较密，飞线从排针之间穿出时注意不要蹭到相邻焊盘；焊完用放大镜或万用表逐对测一遍相邻脚是否短路。
  • MQ-2 有加热丝，长期通电会微热属正常；但不要用热熔胶把它封死，要留散热。
  • DHT11 建议不要直接焊在板上，用 3P 排母做插座并让它稍微「架空」出板面，避免板子自身温升影响读数。

6. 仿真设置与避坑清单（与你的代码直接相关）

Proteus 里必做：
  1. 双击 U1（STM32F103C8），Program File 指向 Keil 编出的 .hex。
  2. Crystal Frequency 设为 8MHz（与 Blue Pill 板载晶振一致）。这一项必须和代码里 SystemInit 的配置一致，否则串口波特率和所有软件延时全错。
  3. Proteus 的 STM32 模型运行用的是模型内部时钟，若代码切了外部晶振，先确认模型属性里的频率与之一致；不一致会直接跑飞。
  • MQ-2 / BH1750 / CH340 在 Proteus 里没有模型，仿真时分别用 POT-HG / I²C 从机 / COMPIM 替代，只验证 ADC 读值与 I²C、串口时序即可。
  • DHT11 仿真模型时序容差比实物宽，仿真能通不代表实物能通，实物上要单独用逻辑分析仪看 DATA 时序。
  • 数值缩放：温度/湿度 ×10（25.6℃ → 0x0100），烟雾/光照不缩放（312 → 0x0138）——别统一乘 10。
  • ST-Link 的 3.3V 不要接。 板子已经由 Micro-USB 供电，再接 ST-Link 的 3.3V 就是两个电源顶在一起。只接 SWDIO / SWCLK / GND 三根。
  • CH340 的 VCC 不要接。 它由自己的 USB 口供电，只接 TXD / RXD / GND 三根最干净，也能避免和板子电源打架。若你的模块是 5V 电平版，记得把跳线挪到 3.3V 档。
  • CH340 必须与板子共地，只接 TX/RX 不接地是"能通电但不通信"最常见的原因。
  • MQ-2 上电后要预热 2~3 分钟读数才稳定，刚上电时的烟雾值偏高属正常。
  • Blue Pill 的 BOOT0 跳线：平时保持 0（板上丝印 0 一侧），用 ST-Link 烧录无需改动；只有走串口 ISP 才需要跳到 1，烧完记得跳回。
