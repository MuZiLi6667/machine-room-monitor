机房环境监测系统 · 原理图参考（裸片 + 万能板焊接版）

主控：STM32F103C8T6（LQFP48 裸芯片）  |  供电：USB 5V → AMS1117-3.3  |  装配：万能板手工焊接（取消面包板 / 杜邦线）

这一版和上一版的区别
上一版假设主控用 Blue Pill 最小系统模块（模块自带晶振、复位、稳压、USB），因此原理图很干净。
这一版按你的选择改用 裸芯片 STM32F103C8T6，所以原理图里 新增了一整块「最小系统」：8MHz 晶振电路、复位电路、BOOT 配置、VDDA 滤波、去耦电容组、USB→3.3V 稳压，以及 SWD 下载口。
下面的接线表、元件清单、焊接步骤全部按「裸片 + 焊接」重做。

5. 万能板焊接装配指南

5.1 布局规划（先在纸上排一遍）

  • 中央：U1（转接板）+ 晶振 Y1 + 去耦电容 C5~C8 —— 晶振紧贴 MCU 的 5/6 脚，去耦电容紧贴电源脚。
  • 左上：电源区 J1 → F1 → U2 → C1/C2/C3/C4，输出 3V3 到板中央的电源母线。
  • 左侧/下方：SW1 复位键、JP1 BOOT 跳线、J2 SWD 口，放在板边方便插拔。
  • 右侧：四个模块（DHT11 / MQ-2 / BH1750 / CH340）用排母做成"插座"，天线的传感器模块悬空或用短线引出，避免发热影响温湿度读数。
  • 电源母线：在万能板上用两根粗铜线（或加锡走粗）分别做 3V3 与 GND 干线，所有器件就近搭接，形成星形地。

5.2 焊接顺序（由矮到高、由小到大）

  1. 先焊 电阻、IC 座/转接板、晶振、小电容（100nF/22pF）——矮、耐热、数量多。
  2. 再焊 AMS1117、电解电容 C1/C3/C8、按键、USB 座、排针排母——较高、怕热。
  3. LQFP48：先对角固定两个脚，再逐边拖焊；或直接买 LQFP48→DIP 转接板，风险最低。
  4. 每焊完一个区域，用万用表测相邻脚是否短路，尤其是 MCU 电源脚与地。
先焊电源、先测电源、再装 MCU。 焊好电源部分后，先只焊 U2 和滤波电容，插上 USB 测 3V3 是否在 3.3±0.1V；确认无误再装 MCU 和其余部分。这一步能避免"一上电就把 MCU 烧了"。

5.3 走线建议

  • 电源线与地线走粗（多用几个焊盘串联，或加锡堆厚）；信号线用 0.3~0.5mm 漆包线飞线，走最短路径。
  • 晶振两根线尽量短且等长，晶振外壳/负载电容就近接地。
  • MQ-2 的分压节点 A 到 PA0 的线尽量短，远离 5V 和 MQ-2 加热丝的走线。
  • I²C（PB6/PB7）与串口（PA9/PA10）分开走，避免平行过长。
  • 所有模块的 GND 都汇到同一根地干线，不要形成地环路。

6. 仿真设置与避坑清单（与你的代码直接相关）

Proteus 里必做：
  1. 双击 U1，Program File 指向 Keil 编出的 .hex。
  2. Crystal Frequency 设为 8MHz（与 Y1 一致）。上一版用模块时写的是 8MHz，裸片版同理，必须和代码里的 SystemInit 一致，否则串口波特率和延时全错。
  3. Proteus 的 STM32 模型运行时用的是模型内部时钟，若代码切了外部晶振，先确认模型属性里的频率与之一致；不一致会直接跑飞。
  • MQ-2 / BH1750 / CH340 在 Proteus 里没有模型，仿真时分别用 POT-HG / I2C 从机 / COMPIM 替代，只验证 ADC 读值与 I²C、串口时序即可。
  • DHT11 仿真模型时序容差比实物宽，仿真能通不代表实物能通，实物上要单独用示波器/逻辑分析仪看 DATA 时序。
  • 数值缩放：温度/湿度 ×10（25.6℃ → 0x0100），烟雾/光照不缩放（312 → 0x0138）——这条和上一版一致，别统一乘 10。
  • 万能板实物上，CH340 必须与板子共地，只接 TX/RX 不接地是最常见的"能通电但不通信"原因。
  • BOOT0 跳线：正常运行时 JP1 必须断开；下载完忘记拔掉跳线帽，会导致下次上电进不了用户程序。
