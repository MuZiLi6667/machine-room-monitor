# 接线表（stm32-firmware）

> 主控：STM32F103C8T6 最小系统板（Blue Pill），3.3V 逻辑电平。

## 引脚对照

| 模块 | 模块引脚 | STM32 引脚 | 接口 | 备注 |
|---|---|---|---|---|
| DHT11 | DATA | **PB5** | 单总线 GPIO（开漏） | VCC 接 3.3V，DATA 需 4.7k~10k 上拉（模块自带可省）；裸元件必须外接 |
| DHT11 | VCC / GND | 3.3V / GND | 电源 | 裸 DHT11 可 3.3V~5V，本系统用 3.3V |
| MQ-2 | AO | **PA0** | ADC1 通道0（12位） | ⚠️ **必须分压**，见下方说明 |
| MQ-2 | VCC / GND | **5V** / GND | 电源 | MQ-2 加热丝需 5V 供电；上电后预热 2~3 分钟 |
| BH1750 | SCL | **PB6** | I2C（软件模拟） | 3.3V 供电，模块自带 3.3V 稳压与上拉 |
| BH1750 | SDA | **PB7** | I2C（软件模拟） | 同上 |
| BH1750 | ADDR | GND | 地址选择 | 接地 = 器件地址 0x23 |
| BH1750 | VCC / GND | 3.3V / GND | 电源 | |
| USB转TTL | RXD | **PA9**（USART1_TX） | UART 115200-8-N-1 | **交叉连接**：模块 RX 接单片机 TX |

## MQ-2 分压电路（重要）

MQ-2 模块 5V 供电时 AO 输出最高可达 5V，而 STM32 ADC 上限为 **3.3V**，直接连接会损坏引脚，必须分压：

```
MQ-2 AO ──[10kΩ]──┬── PA0 (ADC1_CH0)
                  │
                [20kΩ]
                  │
                 GND
```

分压比 = 20/(10+20) = 2/3，PA0 实际电压 ≈ 0.67 × AO，AO 满幅 5V 时 PA0 ≈ 3.3V，安全。
（也可用 10k/10k 分压 = 1/2 比例，更保守，代价是 ADC 量程只用一半。）

## 实际传感器配置

- [x] DHT11（必做）
- [x] MQ-2
- [x] BH1750

若某个传感器缺件/损坏：在 `main.c` 顶部将 `ENABLE_MQ2` / `ENABLE_BH1750` 宏置 0，帧内传感器个数自动减少，帧格式不变（客户端按个数字段自适应）。
